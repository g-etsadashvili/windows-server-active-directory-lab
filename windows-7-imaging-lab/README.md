# Windows 7 Professional — Sysprep and WIM Imaging Lab

## Overview

This project documents my practical work preparing a Windows 7 Professional virtual machine with Sysprep, capturing a WIM image in Windows PE, and deploying the image to a clean test virtual machine using DISM.

## Lab Environment

- Hypervisor: Microsoft Hyper-V
- Source operating system: Windows 7 Professional
- Preparation tool: Sysprep
- Imaging environment: Windows PE
- Image format: WIM
- Image capture and deployment: DISM
