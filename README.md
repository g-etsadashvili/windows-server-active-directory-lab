# Windows Server & Active Directory Lab

## Overview

This repository documents my hands-on learning and lab work with Windows Server 2025, Hyper-V, and Windows network infrastructure.

The objective is to develop practical skills relevant to IT infrastructure and network administration.

## Lab Environment

- **Hypervisor:** Microsoft Hyper-V
- **Server OS:** Windows Server 2025
- **Client OS:** Windows 10 and Windows 11 virtual machines
- **Planned lab domain:** `lab.local`

## Areas of Study

### 1. Hyper-V Virtualization

- Creating and configuring virtual machines
- Configuring virtual disks and virtual hardware
- Understanding virtual switches and network adapters

### 2. Windows Server Administration

- Server Manager and server configuration
- Roles and features
- Basic Windows Server management

### 3. Active Directory Domain Services

- Domain and domain controller concepts
- Active Directory deployment and configuration
- Users, computers, and centralized identity management

### 4. DNS and Network Configuration

- DNS fundamentals and name resolution
- IP configuration and connectivity troubleshooting
- Understanding the relationship between DNS and Active Directory

### 5. Windows Client Integration

- Preparing Windows client virtual machines
- Domain-joining procedures
- Centralized management concepts

### 6. PowerShell

- Windows administration commands
- System configuration and troubleshooting
- Opportunities for administrative automation

## Documentation Approach

Each lab will document its objective, configuration steps, commands, results, and troubleshooting notes.

Tasks will be marked as completed only after they have been performed and verified in the lab.

## Learning Goals

Build practical experience with Windows Server, Active Directory, DNS, virtualization, and enterprise network administration.
